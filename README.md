## 📊 Overview
Comprehensive analysis of 11 global investment instruments across 1M, 1Y, 5Y, and 10Y time horizons.

## 📦 Assets Covered
S&P 500 · NASDAQ 100 · FTSE 100 · DAX · Nikkei 225 · Gold · Silver · Crude Oil · Bitcoin · Ethereum · DXY

## 📐 Metrics
- Total Return & CAGR
- Annualized Volatility
- Sharpe Ratio
- Maximum Drawdown
- Correlation Matrix

## 🔑 Key Findings
- **BTC**: 10Y CAGR of 63.7% — but -76% max drawdown
- **SILVER**: Best 1Y performer (+130%)
- **GOLD**: Most consistent Sharpe ratio across all periods
- **SP500 ↔ NASDAQ**: +0.94 correlation — holding both adds little diversification
- **GOLD ↔ DXY**: -0.38 — genuine hedge against dollar weakness
